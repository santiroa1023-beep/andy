# Portafolio de Bryan Anderei Ruiz Olvera

Sitio web estático desarrollado con HTML, CSS y JavaScript.

## Archivos

- `index.html`: estructura del portafolio.
- `styles.css`: diseño y estilos visuales.
- `script.js`: menú móvil y año automático.
- `andy.png`: fotografía de perfil (la debes agregar tú).

## Agregar la fotografía

Copia la imagen de Bryan dentro de esta misma carpeta y conserva exactamente este nombre:

`andy.png`

La imagen debe quedar al mismo nivel que `index.html`, `styles.css` y `script.js`.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta directamente a la raíz del repositorio `andy`. No subas una carpeta contenedora adicional. En GitHub Pages selecciona la rama `main` y la carpeta `/(root)`.
